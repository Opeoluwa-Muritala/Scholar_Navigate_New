# 📚 Scholar Navigate

A productivity app for students to manage tasks, collaborate in real-time, and stay on track — built with Jetpack Compose and Firebase.

---

## ✨ Features

- ✅ Create and organize personal and shared tasks
- ✅ Real-time updates via Firebase Firestore
- ✅ Task prioritization and reminder support
- ✅ Offline-first architecture using Room
- ✅ Clean MVVM architecture and Compose UI

---

## 📱 Tech Stack

| Category      | Tools Used                                     |
|---------------|------------------------------------------------|
| Language      | Kotlin                                          |
| UI            | Jetpack Compose, Material Design 3              |
| Architecture  | MVVM, Room, Firebase                            |
| Backend       | Firebase Authentication, Firestore              |
